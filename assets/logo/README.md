# Logo (Bogen-Marke)

| Datei | Zweck |
|---|---|
| `Schmalo S Unternehmen.png` | Original: Logo quer mit Schrift, Hintergrund #0F2438 |
| `Schmalo S Unternehmen (1).png` | Original: Bildzeichen ohne Schrift, Hintergrund #0F2438 |
| `logo-quer-transparent.png` | freigestellt, für Kopf- und Fußzeile (weiße Schrift, nur auf dunklem Grund) |
| `logo-zeichen-transparent.png` | freigestellt, Bildzeichen |

Aus den Originalen erzeugt `node scripts/logos.cjs` die freigestellten Dateien sowie
`public/favicon-32.png`, `favicon-48.png`, `apple-touch-icon.png`, `icon-192.png`,
`icon-512.png` und das Vorschaubild `public/og-image.png` (1200 × 630).
Nach neuen Originalen einfach erneut ausführen.

Für helle Flächen (Briefpapier, Whitepaper-Innenseiten) wird eine Version mit
dunkler Schrift benötigt, idealerweise als SVG.
