# Logo-Dateien (Bogen-Marke)

Entscheidung 10/2026: **Bogen-Marke** (goldene Bildmarke aus Bogensegmenten).
Dateien hier ablegen, dann baue ich sie in Header, Footer, Favicon und
Social-Vorschau ein.

| Datei | Inhalt | Einsatz |
|---|---|---|
| `logo-horizontal-hell.svg` | Marke links, „Schmal / Unternehmensberatung“ rechts, für hellen Grund | Briefkopf, Rechnung, Signatur |
| `logo-horizontal-dunkel.svg` | dasselbe für dunklen Grund (Navy) | Website-Header, Footer |
| `logo-gestapelt-hell.svg` | Marke oben, Schrift darunter, heller Grund | Präsentationen, Druck |
| `logo-gestapelt-dunkel.svg` | dasselbe für dunklen Grund | Social Media, Titelfolien |
| `bildmarke.svg` | nur die Marke, ohne Hintergrund | Favicon, Profilbilder, App-Icon |
| `bildmarke-einfarbig.svg` | nur die Marke, eine Farbe, ohne Verlauf | kleine Größen, Stempel, Fax |

Anforderungen an die Designerin bzw. den Designer:
- Vektor (SVG), Texte in Pfade umgewandelt, ohne eingebettete Pixelbilder.
- Farben in den Markenwerten: Navy `#1A3A5C`, Navy Deep `#0F2438`,
  Gold `#C9A87C` (nicht das lilastichige Blau aus den Entwürfen).
- Kein Hintergrundrechteck in den Dateien, außer ausdrücklich gewünscht.
