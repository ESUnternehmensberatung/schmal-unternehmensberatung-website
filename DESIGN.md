# Design

Status: **Richtung festgelegt** – Feinschliff (Schriftwahl, Komponenten) in der
Bauphase mit dem Skill `homepage-design`.

## Design Read
Reading this as: persuasive OnePager for owner-managers of German family SMEs,
with a calm, confident, editorial-industrial language, leaning toward a
Swiss-ordered layout, classic serif headlines and real photography.

## Referenzen
erkert.de (Stolz, echte Fotos, harte Zahlen) · marktplatz.io (regional,
partnerschaftlich) · markel.ch (Ordnung, wenig Ornament) · urbanpower.net
(nummerierte Schritte, Lesbarkeit vor Effekt).

## Farben

| Token | Hex | Einsatz |
|---|---|---|
| `--navy` | `#1A3A5C` | Primär, Headlines auf hell, Flächen |
| `--navy-deep` | `#0F2438` | Hero-Overlay, dunkle Sektionen, Footer |
| `--gold` | `#C9A87C` | Akzent, Primär-Button, Linien – nur auf dunkel |
| `--gold-deep` | `#7A5C33` | Gold für Text/Links auf hell (5,6 : 1) |
| `--ivory` | `#F7F4EE` | Seitenhintergrund |
| `--white` | `#FFFFFF` | Karten, Formulare |
| `--ink` | `#1A2330` | Fließtext (14,4 : 1) |
| `--stone` | `#5A6572` | Sekundärtext (5,4 : 1) |
| `--line` | `#E3DDD2` | Trennlinien |

Regeln: Gold max. ein Akzent pro Bildschirm · Primär-Button Gold + Navy-Deep-Text
(7,1 : 1) · keine Verläufe außer dem Foto-Overlay im Hero.

## Typografie
Serif-Headlines (Tradition, Souveränität) + ruhige Grotesk für Text
(Präzision). Große, lesbare Grundgröße (≥ 18 px). Akzentwort in Headline kursiv
in Gold (wie Entwurf). Finale Schriftpaarung in der Bauphase.

## Layout
- Klares 12-Spalten-Raster, großzügiger Weißraum, linksbündige Texte.
- Nummerierte Module für Ablauf und Leistungen.
- Echte Fotos, keine Stockbilder, keine KI-Illustrationen, keine Icons-Flut.
- Hero: Foto rechts, dunkles Navy-Overlay links, Kennzahlenleiste unten.

## Bewegung
Zurückhaltend: sanftes Einblenden beim Scrollen, präzise Hover-/Press-Zustände.
Keine Endlos-Animationen, kein Parallax-Feuerwerk. Werte nach Emil Kowalski.

## Verboten
Laut, verspielt, billig, AI-Slop: keine Lila-Verläufe, kein Glassmorphism,
keine drei gleichen Icon-Karten, keine Buzzword-Überschriften, keine
Platzhalterzahlen.
