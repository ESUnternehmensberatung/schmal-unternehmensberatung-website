# Technik & Betrieb

| Thema | Entscheidung / Vorschlag |
|---|---|
| Umfang | OnePager + Blog (Business-Concierge-Produkte) |
| Pflege | Inhaber selbst → Inhalte als Markdown-Dateien im Repo |
| Hosting | Eigene Domain + GitHub; statische Seite (z. B. Astro) über GitHub Pages oder Netlify |
| Terminbuchung | Google Kalender – Terminbuchungsseite für die Quick-Win-Analyse, auf der Seite eingebettet |
| Vorqualifizierung | 3 Fragen vor der Buchung: Unternehmensgröße, größter Zeitfresser, Rolle |
| Angebot anfordern | Formular (Name, Firma, Anliegen) → E-Mail |
| Newsletter | Anmeldung über Whitepaper-Download; DSGVO: Double-Opt-in, Tool nötig (z. B. Brevo oder MailerLite) |
| CRM | keins |
| Recht | Impressum, Datenschutz, Provisions-Hinweis im Business-Concierge/Blog |
