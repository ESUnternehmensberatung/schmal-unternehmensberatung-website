# Technik & Betrieb

| Thema | Entscheidung / Vorschlag |
|---|---|
| Umfang | OnePager + Blog (Business-Concierge-Produkte) |
| Pflege | Inhaber selbst → Inhalte als Markdown-Dateien im Repo |
| Hosting | Eigene Domain + GitHub; statische Seite (z. B. Astro) über GitHub Pages oder Netlify |
| Terminbuchung | Google Kalender – Terminbuchungsseite, 45 Min., verlinkt nach Jotform-Vorabfragen |
| Vorqualifizierung | 3 Fragen vor der Buchung: Unternehmensgröße, größter Zeitfresser, Rolle |
| Formulare | **Jotform (EU-Hosting)**, eingebettet: Angebot anfordern, Vorab-Fragen Quick-Win-Analyse, Whitepaper-Download |
| Angebot anfordern | Jotform: Name, Firma, Mitarbeiterzahl, Anliegen |
| Newsletter | Anmeldung über Whitepaper-Download per Jotform; DSGVO: Einwilligungs-Checkbox + Double-Opt-in (Bestätigungsmail) |
| CRM | keins |
| Recht | Impressum, Datenschutz, Provisions-Hinweis im Business-Concierge/Blog |
| Preise | **keine Paketpreise** – individuelles Angebot nach Quick-Win-Analyse |
| Bilder | `assets/hero.png`, `assets/about.png` → beim Bau als WebP/AVIF optimiert |
